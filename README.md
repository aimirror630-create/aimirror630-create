## Как это работает в реальном мире

- **QR на фасаде** — гость сканирует → звонит аватару → «Ну, заходи, расскажу как строил…»
- **Веб-виджет** — кнопка «позвонить» на сайте объекта, посетитель не уходит
- **Музейный терминал** — интерактивный киоск в холле, трубка или микрофон
- **Экскурсионный тур** — 10–15 ключевых точек, аватар ведёт гостя по зданию

Без гида. Без персонала. Без электричества. 24/7.
